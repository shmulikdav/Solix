# Archived docs

These describe Solix as it was around 1.7 (mid-2026), before Maestro, the gate,
approval rules and levels. Commands and behaviour in them may no longer be
accurate. They are kept for history, not as instructions.

| File | Was | Use instead |
|---|---|---|
| `CLI.md` | Every `solix` subcommand | `solix --help`, `solix <command> --help` |
| `OPERATING.md` | Running Solix day to day | [README](../../README.md) |
| `SOLIX_DOCS_BUNDLE.md` | All the docs in one file | [README](../../README.md), [`docs/`](..) |
| `DEMO_DEV.md` | The from-source developer guide | [`CONTRIBUTING.md`](../../CONTRIBUTING.md) |
| `DEMO.md`, `DEMO_PM.md` | First-look guides for non-developers and PMs | [`docs/BETA.md`](../BETA.md) |

A follow-up to 1.20.4, found by checking its result on a real machine. **1,413 tests. 51 claims in `docs/CLAIMS.md`, each with a test that fails when it stops being true.**

## What 1.20.4 missed

1.20.4 retires sessions whose `claude` has ended. On the machine it was written for, that took the count from **481 sessions to 8**. But only one of the 8 was a running `claude`:

| What was at the recorded pid | Count | Why it was kept |
|---|---|---|
| Other programs: system services, the Dock, another app | 4 | macOS had **reused** the numbers. The sweep only asked "is something running at this pid?", and something was. |
| A login shell | 1 | Reused, or a hook that reported its shell |
| pid 1 (`launchd`), from a hook whose parent had already exited | 1 | Can't be judged |
| No pid recorded at all | 1 | Can't be judged |

## The fix

- **It checks which program holds the pid, not just that the pid is in use.** When a session's events arrive, Solix records which program holds its pid, and since when. If a different program is there later, or one that started after the session was last heard from, the number was reused and the session is retired.
- **A shell at the pid while the session's events arrive** means the hook reported its parent shell, not the agent. That session is never judged by the pid, rather than retired and revived every minute.
- **It says what it did.** On startup: `[solix] retired 463 sessions whose claude process had ended (their history stays in the database)`.

`CLAIM-DEAD-SESSIONS-RETIRE` is tested against real processes. That includes a process that started after the session went quiet, a shell, and a pid held by a different program.

## The counts show the fleet right now

Some sessions can't be judged with certainty: a pid of 0 (backfilled history) or 1. The top bar, and the band above the Claude Code prompt, now count by the galaxy's rule: an idle session quiet for over a day isn't counted, whichever way the Galaxy's show/hide toggle is set. They're still in List, and their spend still counts. `CLAIM-GALAXY-HIDES-QUIET`.

## Upgrading

```sh
npm i -g @shmulikdav/solix
solix stop && solix
```

Wait until `npm view @shmulikdav/solix version` prints `1.20.5` before installing. The registry can take a few minutes after a release.
